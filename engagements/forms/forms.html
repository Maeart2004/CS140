Form Review Questions & Answers

The form tag has an "action" attribute. What does it do?

- The action attribute specifies the URL or file path (for example, formprocessing.html) where the browser sends the form data when the user clicks the submit button.

The form tag has a "method" attribute. What does it do?

- The method attribute specifies the HTTP method (GET or POST) the browser uses to send the form data to the server.

What is the difference between a "POST" and a "GET"?

- GET appends form data directly to the URL query string, making it visible in the address bar (less secure for sensitive data like passwords). POST sends form data hidden inside the HTTP request body, which is much more secure for sensitive information.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder?

- Difference: A pre-set value is actual data submitted to the server if unchanged. A placeholder is a temporary visual hint that disappears when typing and is not submitted.
• Text box: Pre-set via value="Default", hint via placeholder="Hint".
• Textarea: Pre-set by placing text between tags (<textarea>Default text</textarea>), hint via placeholder.
• Select box: Pre-set by adding the selected attribute to an option (<option selected>Option</option>).
• Checkbox/Radio: Pre-set by adding the checked attribute (checked).

List all the form controls that HTML5 added. Which ones did you put in your form?

- HTML5 input types added: email, url, tel, number, range, date, month, week, time, datetime-local, color, and search. I included the email and date controls in my form.

What are different ways to style your form?

- Inline, internal, external CSS, as well as modern layout models like Flexbox and Grid.

Why does the professor like to use flex?

- It makes aligning elements and responsive page flow much easier and cleaner.

What makes for a good mobile form?

- Large tap targets, readable font sizes, appropriate input keyboards (like email or numeric), and clear spacing so users can easily navigate on smaller screens.
