The form tag has an "action" attribute. What does it do?

-The action attribute specifies the URL or file path, for example, formprocessing.html. Where the browser sends the data form when the user clicks submit button

The form tag has a "method" attribute. What does it do?

-The method attribute specifies the HTTP method (GET or POST) the browser uses to send the data form to the server.

What is the difference between a "POST" and a "GET"?

-GET appends form data directly to the URL query string. It is usually visible in the address bar which is not secure for sensitive data like passwords. On the other hand, POST usually sends form data hidden inside the HTTP request body which helps secure for sensitive data.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder? Answer for each of these: text box, textarea, select box, checkbox, and radio button.

-Difference: A pre-set value is actual data that gets submitted to the server if left unchanged. A placeholder is a temporary visual hint that disappears as soon as the user types, and it is not submitted. Text box: Pre-set via the value attribute (value="Default"), hint via the placeholder attribute (placeholder="Hint"). Textarea: Pre-set by placing text between the tags (), hint via the placeholder attribute. Select box: Pre-set by adding the selected attribute to a specific option (<option selected>Option</option>) Checkbox: Pre-set by adding the checked attribute (), placeholders do not apply. Radio button: Pre-set by adding the checked attribute (), placeholders do not apply.
