1. How are the Internet and Web different?

The internet can work without the web but the web cannot work without the internet because the internet is the network and the web is what runs in the network.

2. ASCII and Unicode

ASCII has only 128 characters and is a small alphabet for old computers meanwhile Unicode has around 150,000 characters and is a giant alphabet for all languages.

3. What is UTF-8

This is how letters are saved as 0s and 1s on the computer because it can only understand 0 and 1.

4. URL

It is short for uniform resource locator where it redirects when clicked to the complete address of a web page.

5. Domain Name

It is like a nickname that represents as an IP address.

6. HTTP

It is the language the browser and server used to communicate with each other but is not secure.

7. HTTPS

It is the same as HTTP but is secure. It's like having a private conversation with someone.

8. IP Address

It is a unique home address of every device on the internet.

9. DNS

It turns names that we know into numbers so the computer can read it.

10. W3C Recommendations

It's an organization who makes the rules for the web that we need to follow.

11. XML, XHTML, HTML, HTML5

These are all related to one another and people before used these but we now uses HTML5 because it is newer or updated.
